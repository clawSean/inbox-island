# Support

For ordinary product questions and reproducible synthetic bugs, use:

https://github.com/clawSean/inbox-island/issues

Include the Inbox Island version, browser/version, visible error code, and safe
reproduction steps. Do not include credentials, tokens, account lists, raw
email, mailbox screenshots, or private browser/profile data.

Security vulnerabilities must use the private channel in `SECURITY.md`.
Google account access can be revoked independently at:

https://myaccount.google.com/connections
