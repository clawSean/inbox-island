## Detailed description

> Inbox Island helps you find recent Gmail threads that likely need a reply or
> attention, while leaving Gmail unchanged.
>
> You choose the Google account and start each sync. Inbox Island reads a
> bounded recent Inbox/Sent slice, classifies it in your browser, and groups
> threads into Needs me, Review, Waiting, Records, Low signal, and All mail.
> Every real result can open the exact thread in Gmail.
>
> Privacy by architecture:
> • Mail goes directly from Google to your browser.
> • No Inbox Island server, cloud AI, telemetry, ads, or remote code receives
>   mailbox content.
> • OAuth access is short-lived and memory-only.
> • Raw bodies, HTML, attachments, summaries, and OAuth credentials are not
>   persisted.
> • Only minimal account-scoped derived triage state is stored locally.
>
> Google classifies `gmail.readonly` as a restricted scope. It can read mailbox
> content, but Inbox Island cannot send, reply, edit, label, archive, delete, or
> mark messages read. Inbox Island voluntarily limits each run, but the Google
> grant itself is broader than that runtime limit.
>
> Try the disconnected synthetic demo without a Google account. Triage is
> advisory; Gmail remains the source of truth.
